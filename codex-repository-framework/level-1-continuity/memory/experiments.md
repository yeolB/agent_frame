# Experiment and Decision Ledger

This file contains durable lessons that future sessions must not rediscover. It is not a chronological dump of every run.

Add an entry when an experiment changes a decision, rejects an approach, exposes an important condition, or prevents likely repetition. Keep raw logs and large outputs elsewhere and link them.

## Entry template

### EXP-<number>: <short decision title>

- Date: YYYY-MM-DD
- Goal criterion: <link or exact heading from GOAL.md>
- Hypothesis: <claim tested>
- Experiment: <controlled change, baseline, and material assumptions>
- Result: <decision-relevant evidence>
- Interpretation: <what the result supports and does not support>
- Decision: <accept, reject, pause, or revise>
- Next action: <next experiment or reason to stop>
- Do not repeat: <the recognizable failed pattern and conditions, if applicable>
- Evidence: <paths, commands, run IDs, or commits>
